# 修正内容（2026-03-17）

## 1. 管理者レビュー一覧の取得失敗対応

### 変更ファイル

- `app/admin/reviews/page.tsx`
- `ARCHITECTURE.md`

### 修正内容

**fetcher の変更（`app/admin/reviews/page.tsx`）**

- `fetch` のレスポンスで `res.ok` をチェックするように変更。
- `!res.ok` のときは `throw new Error(...)` し、SWR の `error` に渡す。
- 403 かつ body の `error === "Forbidden"` のときは「管理者権限がありません。」と表示。
- その他の 4xx/5xx は「取得に失敗しました (ステータスコード)」と表示。

**ARCHITECTURE.md**

- 「前提条件・制約」に、管理者用レビュー一覧利用時は `.env` の `ADMIN_EMAILS` を設定すること（未設定またはメールが含まれない場合は 403）を追記。
- 変更履歴に、上記 fetcher 修正と ADMIN_EMAILS の前提追記を記載。

### 運用上の対処

管理者として一覧を表示するには、`.env` に次を設定し、サーバー再起動が必要。

```env
ADMIN_EMAILS="ログインに使っているGmailアドレス"
```

複数人ならカンマ区切りで記載。
