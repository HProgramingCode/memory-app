# 02 — デッキ詳細から「復習と同じ見た目」でプレビュー

## やりたいこと

デッキ詳細（`/decks/[id]`）のカード一覧から、**編集画面ではなく**、**テスト（復習）時と同じ見た目**で 1 枚だけ確認したい。

## 仕様

| 項目 | 内容 |
|------|------|
| 入口 | 一覧行の **目アイコン**（Visibility） |
| URL | `/review?deckId={デッキID}&mode=preview&cardId={カードID}` |
| 表示 | 既存の復習 UI（3D フリップ、Markdown、[`CardImage`](../../../components/review/CardImage.tsx)） |
| SRS | **更新しない**（`applyReview` しない） |
| 学習記録 | **付けない**（`recordReview` / `recordFreeStudy` しない） |
| 表面→裏面後 | **「デッキに戻る」** のみ（`Space` / `Enter` でも可） |
| ヘッダー × | **`/decks/{deckId}`** に戻る（ダッシュボードではない） |
| 不正な `cardId` 等 | メッセージ付きでデッキへ戻る導線 |

## 変更ファイル

- [`app/decks/[id]/page.tsx`](../../../app/decks/[id]/page.tsx) … プレビュー用 `IconButton` + `stopPropagation`（行クリックで編集に飛ばないように）  
- [`app/review/page.tsx`](../../../app/review/page.tsx) … `mode=preview` と `cardId` の分岐、キーボード、完了画面の例外  
- [`ARCHITECTURE.md`](../../../ARCHITECTURE.md) … フロー説明・4-6 補足・変更履歴

## 実装の要点（次に自分で足すとき）

1. **新しい画面を作らず**、既存 `review/page.tsx` に **クエリでモード分岐**する。  
2. プレビュー時は `useEffect` の先頭で **対象を 1 枚の配列**にし、自由学習の「続きから」ダイアログは **出さない**（`showStartDialog && !isPreviewMode` など）。  
3. `getLastStudyIndex` の更新 effect は **プレビューでは動かさない**（デッキの続きインデックスを汚さない）。

## 確認方法

1. デッキ詳細で目アイコン → プレビュー表示になる。  
2. 答えを見る → デッキに戻る。  
3. 復習を数枚こなしたあと、プレビューで **SRS や枚数が変わっていない**こと（別途 DB / 画面で確認）。
