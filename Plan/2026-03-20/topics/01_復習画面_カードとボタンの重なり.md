# 01 — 復習画面でカード内容とボタンが重なる

## 事象

`/review`（および自由学習・プレビューで同じ UI を使う画面）で、**長いテキスト**や**大きい画像**があると、カードの表示が下の「答えを見る」「難しい／普通／簡単」などの**ボタンと重なって見える**。

## 原因（技術）

1. **3D フリップ用 CSS**（[`app/globals.css`](../../../app/globals.css)）で、表面・裏面が `position: absolute` になっている。  
2. 絶対配置の子は**親のレイアウト上の高さにほとんど寄与しない**。親は `min-height: 300px` 程度のまま。  
3. 実際の Markdown・画像はその高さを超えて**はみ出し描画**（`overflow` 既定は visible）。  
4. その下に、通常フローで**ボタン用の `Box`** が置かれているため、**見た目だけボタンと重なる**。

## 実装した対応

**ファイル:** [`app/review/page.tsx`](../../../app/review/page.tsx)

1. プログレスバー直下のメインカラムに `flex: 1` と `minHeight: 0` を付与し、**残りのビューポート高さ**をこのエリアが使えるようにした。  
2. カード（`.card-flip-container` を包む部分）を **`overflowY: "auto"`** の領域の内側に置き、**長い内容はカードエリア内でスクロール**するようにした。  
3. ボタン行の `Box` に **`flexShrink: 0`** を付け、**常に下に領域を確保**するようにした。

### 追調整（スクロールバー・先頭揃え）

最初の案では、スクロール枠に `display: flex` + `justifyContent: center` を付けていた。  
これだと **短いカードでもスクロールが出たり**、挙動が分かりにくいことがあった。

- スクロール枠は **ブロック配置**に戻し、カードは**上から**並ぶ。  
- `overflow-y: auto` のままなので、**はみ出すときだけ**スクロールが効く。

## 触っていないもの

- [`app/globals.css`](../../../app/globals.css) のフリップ用 `absolute` は**そのまま**（挙動を変えず、レイアウト側で吸収）。

## 確認方法

1. 長文または大きい画像のカードで `/review` を開く。  
2. ボタンと本文が**重ならない**こと。  
3. カード部分だけ**縦スクロール**できること。  
4. 短いカードでは**余計なスクロールバーが常時出ない**こと（OS の「スクロールバー常時表示」設定は除く）。
