## study ディレクトリについて

### 目的
- ジュニアエンジニアでも理解しやすい形で、Memory App の**セットアップ手順・設計メモ・機能解説・調査メモ**を整理しておくための場所です。
- 詳細で正式な要件・設計は `requirements/` や `ARCHITECTURE.md` を参照し、ここでは「実務で手を動かすときに知りたいこと」をコンパクトにまとめます。

### 構成
- `study/setup/` : 環境構築やデプロイなどの手順書
- `study/architecture/` : システム全体や認証・DB・画像管理などの設計メモ
- `study/features/` : 機能ごとの解説（インポート/エクスポート、レビュー機能など）
- `study/seo/` : SEO 対応の方針とチェックリスト
- `study/decisions/` : 重要な設計判断のメモ（なぜそうしたか）
- `study/_templates/` : 新しいメモを書くときのテンプレート
- `study/_archive/` : 過去に作成した md を一時的に退避する場所

### 書き方のガイドライン
- 1ファイル1テーマを基本にします。
- 冒頭に「対象読者」「前提」「ゴール」を簡潔に書きます。
- 手順は番号付きリストで、コード例はコードブロックで示します。
- 詳細仕様や最新の要件は、必要に応じて `requirements/` や `ARCHITECTURE.md` へリンクします。
