# E2E: カード作成 → 学習実行

**シナリオ:** デッキ詳細からカードを1枚追加し、復習または自由学習でそのカードが出現するまでを確認する。

## 対象ファイル・URL

- デッキ詳細: `app/decks/[id]/page.tsx` → `/decks/:id`
- カード新規: `app/cards/new/page.tsx` → `/cards/new?deckId=:id`
- 復習: `app/review/page.tsx` → `/review` または `/review?deckId=:id&mode=free`
- API: `POST /api/cards`, `GET /api/cards`, `POST /api/cards/:id/review`, `POST /api/study-records`

## 前提条件

- 認証済み。少なくとも1つのデッキが存在する（シードまたは前ステップで作成）。

---

## TC-E2E-02-01: デッキ詳細から「カードを追加」で新規カード登録画面に遷移する

| 項目 | 内容 |
|------|------|
| 手順 | 1. トップからデッキ一覧のいずれかをクリックして `/decks/:id` へ。<br>2. 「カードを追加」ボタンをクリックする。 |
| 期待 | `/cards/new?deckId=:id` に遷移し、「カードの登録」と表面・裏面の入力欄が表示される。 |
| 検証 | URL に `deckId` が含まれる。見出し「カードの登録」またはフォームが表示される。 |

**セレクタ例:** カード追加ボタンは `AddIcon` 付き。「カードを追加」テキストで `getByRole('button', { name: /カードを追加/ })` を想定。

---

## TC-E2E-02-02: 表面・裏面を入力して保存するとカードが作成され、デッキ詳細に戻る

| 項目 | 内容 |
|------|------|
| 手順 | 1. `/cards/new?deckId=:id` で表面・裏面に任意のテキスト（例: 「Q」「A」）を入力。<br>2. 保存ボタンをクリックする。 |
| 期待 | 保存成功後、`/decks/:id` に遷移する。一覧に今作成したカード（表面テキスト）が1件表示される。 |
| 検証 | デッキ詳細ページで、入力した表面テキストが含まれるリスト項目が存在する。 |

**実装メモ:** `CardForm` の保存は API + ストア更新。Toast で成功メッセージが出る場合もある。

---

## TC-E2E-02-03: 復習「学習を開始する」から復習画面に入り、カードが1枚以上あるときカードが表示される

| 項目 | 内容 |
|------|------|
| 手順 | 1. トップ (`/`) で「学習を開始する」ボタンをクリック。<br>2. `/review` に遷移する。 |
| 期待 | 今日復習対象のカードが1枚以上ある場合、復習画面でカード（表面）が表示される。0枚の場合は「今日の復習はありません」等の完了表示になる。 |
| 検証 | カードがある場合: 表面テキストまたは「答えを見る」ボタンが存在する。カードが0枚の場合: 完了メッセージや「ダッシュボードに戻る」等が存在する。 |

**実装メモ:** シードで「今日 due のカード」を用意しておくか、直前でカード作成し `nextReviewDate` が今日のカードになっている必要がある。`getDueCards()` は `nextReviewDate <= 今日` でフィルタしている。

---

## TC-E2E-02-04: デッキの「自由学習」から該当デッキのカードが並ぶ復習画面になる（オプション）

| 項目 | 内容 |
|------|------|
| 手順 | 1. デッキ詳細 `/decks/:id` で「自由学習」ボタンをクリック。<br>2. `/review?deckId=:id&mode=free` に遷移する。 |
| 期待 | そのデッキの全カードが対象となり、復習画面でカードが表示される（枚数はデッキのカード数と一致）。 |
| 検証 | 少なくとも1枚カードが表示される（デッキにカードがある場合）。 |

**実装メモ:** `mode=free` かつ `deckId` があるとき `getCardsByDeckId(deckId)` で全カード取得。
