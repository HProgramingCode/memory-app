# E2E: ログイン → ダッシュボード表示

**シナリオ:** ユーザーがログインし、トップページでダッシュボードが表示されることを確認する。

## 対象ファイル・URL

- ページ: `app/page.tsx` → `/`
- ログイン: `app/login/page.tsx` → `/login`
- コンポーネント: `components/dashboard/Dashboard.tsx`, `TodayReviewCard.tsx`, `DeckList.tsx`

## 前提条件

- 認証済みセッションを `storageState` で再利用する（またはテスト用ログイン処理を用意する）。
- シードデータでテストユーザー・デッキ・カードが存在する状態を推奨。

---

## TC-E2E-01-01: 未認証でトップにアクセスしたとき、ログイン案内または空ダッシュボードが表示される

| 項目 | 内容 |
|------|------|
| 手順 | 1. 未認証状態で `GET /` にアクセスする |
| 期待 | ログイン画面（`/login`）にリダイレクトされるか、またはトップで空のダッシュボード（カード0・デッキ0）が表示される。いずれもエラーで落ちないこと。 |
| 検証 | URL が `/` または `/login`。画面に「Memory App」または「今日の復習」「デッキ」などの文言が含まれる。 |

**実装メモ:** NextAuth の設定次第で未認証時は `/login` に飛ぶか、`/` で空データになるか変わる。現状の `app/page.tsx` は未認証でも `Dashboard` を空データで表示している。

---

## TC-E2E-01-02: 認証済みでトップにアクセスしたとき、ダッシュボードが表示される

| 項目 | 内容 |
|------|------|
| 手順 | 1. 認証済みの `storageState` で `GET /` にアクセスする |
| 期待 | ダッシュボードが表示され、以下が確認できる。<br>・「今日の復習」セクション（枚数または「ALL CLEAR!」）<br>・統計（カード数・ストリーク・今日の学習数など）<br>・デッキ一覧（存在する場合） |
| 検証 | `role=heading` や「今日の復習」「学習を開始する」などのテキストが含まれる。`/login` にリダイレクトされていない。 |

**セレクタ例（実装時）:**

- 今日の復習カード: ボタン「学習を開始する」→ `getByRole('button', { name: /学習を開始する/ })`
- デッキ一覧: `DeckList` 内のリンクや「自由学習」ボタン

## TC-E2E-01-03: ログインページで Google ログインボタンが表示される

| 項目 | 内容 |
|------|------|
| 手順 | 1. `GET /login` にアクセスする |
| 期待 | 「Memory App」タイトルと「Google でログイン」ボタンが表示される。 |
| 検証 | `getByRole('button', { name: /Google でログイン/ })` が存在する。 |

**実装メモ:** 実際の OAuth 遷移は E2E ではモックまたは手動で済ませ、ボタン表示のみ検証する想定。
