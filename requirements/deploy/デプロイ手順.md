# Memory App デプロイ手順

> **対象**: Vercel + Turso 構成  
> **前提**: ローカルで動作確認済み、テスト完了済み

---

## 概要フロー

```
1. 事前準備（環境変数・Turso）
      ↓
2. Vercel プロジェクト作成
      ↓
3. 環境変数設定
      ↓
4. デプロイ実行
      ↓
5. 動作確認
```

---

## 1. 事前準備

### 1-1. Turso のセットアップ（未実施の場合）

Turso が未セットアップの場合は [requirements/turso/Turso手順.md](../turso/Turso手順.md) を参照。

**確認項目**:
- [ ] `turso db show memory-app-db --url` で URL が取得できる
- [ ] `turso db tokens create memory-app-db` でトークンが発行できる
- [ ] スキーマが適用済み（テーブルが存在する）

### 1-2. 環境変数の準備

以下の値を手元に用意しておく：

| 変数名 | 取得方法 |
|--------|----------|
| `TURSO_DATABASE_URL` | `turso db show memory-app-db --url` |
| `TURSO_AUTH_TOKEN` | `turso db tokens create memory-app-db` |
| `AUTH_SECRET` | `npx auth secret` で生成、または既存の値 |
| `AUTH_GOOGLE_ID` | Google Cloud Console から取得 |
| `AUTH_GOOGLE_SECRET` | Google Cloud Console から取得 |

### 1-3. Google OAuth のリダイレクト URI 追加

Google Cloud Console で、本番用のリダイレクト URI を追加：

```
https://your-app.vercel.app/api/auth/callback/google
```

> **注意**: デプロイ後に Vercel の URL が確定してから追加でも OK

## 2. Vercel プロジェクト作成

### 方法 A: Vercel CLI（推奨）

```bash
# Vercel CLI をインストール（未インストールの場合）
npm i -g vercel

# ログイン
vercel login

# プロジェクト作成 & デプロイ（初回）
vercel
```

対話式で以下を選択：
- `Set up and deploy?` → **Y**
- `Which scope?` → 自分のアカウント
- `Link to existing project?` → **N**（新規作成）
- `Project name?` → `memory-app`（任意）
- `Directory?` → `./`（そのまま Enter）

### 方法 B: Vercel ダッシュボード

1. https://vercel.com/new にアクセス
2. **Import Git Repository** で GitHub リポジトリを選択
3. **Framework Preset** は `Next.js` を選択

---

## 3. 環境変数設定

### Vercel CLI の場合

```bash
# 環境変数を追加（本番用）
vercel env add TURSO_DATABASE_URL production
vercel env add TURSO_AUTH_TOKEN production
vercel env add AUTH_SECRET production
vercel env add AUTH_GOOGLE_ID production
vercel env add AUTH_GOOGLE_SECRET production
```

> 各コマンド実行後、値を入力するプロンプトが表示される

### ダッシュボードの場合

1. Vercel ダッシュボード → プロジェクト → **Settings** → **Environment Variables**
2. 以下を追加：

| Name | Value | Environment |
|------|-------|-------------|
| `TURSO_DATABASE_URL` | `libsql://...` | Production |
| `TURSO_AUTH_TOKEN` | トークン値 | Production |
| `AUTH_SECRET` | シークレット値 | Production |
| `AUTH_GOOGLE_ID` | Google Client ID | Production |
| `AUTH_GOOGLE_SECRET` | Google Client Secret | Production |

## 4. デプロイ実行

### CLI の場合

```bash
# 本番デプロイ
vercel --prod
```

### ダッシュボード / GitHub 連携の場合

- `main` ブランチにプッシュすると自動デプロイ
- または **Deployments** タブから手動でトリガー

## 5. 動作確認

### 5-1. 基本確認

| 確認項目 | 手順 |
|----------|------|
| ページ表示 | `https://your-app.vercel.app` にアクセス |
| ログイン | Google 認証でログインできる |
| デッキ作成 | 新規デッキが作成できる |
| カード追加 | カードを追加できる |

### 5-2. Turso でデータ確認

```bash
turso db shell memory-app-db "SELECT * FROM User ORDER BY createdAt DESC LIMIT 3;"
turso db shell memory-app-db "SELECT * FROM Deck ORDER BY createdAt DESC LIMIT 3;"
```

### 5-3. ログ確認（エラー時）

```bash
vercel logs
```

または Vercel ダッシュボード → **Logs** タブ

---

## トラブルシューティング

### 「環境変数が見つからない」エラー

- Vercel の環境変数が `Production` に設定されているか確認
- **再デプロイが必要**（環境変数追加後は反映されない場合あり）

### Google 認証でエラー

- Google Cloud Console のリダイレクト URI に本番 URL が追加されているか確認
- `AUTH_GOOGLE_ID` / `AUTH_GOOGLE_SECRET` が正しいか確認

### DB 接続エラー

- `TURSO_DATABASE_URL` と `TURSO_AUTH_TOKEN` が正しいか確認
- Turso にスキーマが適用されているか確認：
  ```bash
  turso db shell memory-app-db ".tables"
  ```
